## 用户确认的方向

- 使用可旋转、缩放、定位城市的 3D 地球，呈现真实测评覆盖范围。
- 不使用黑色独立背景或卫星地表纹理。抽象海洋、陆地、经纬线直接取 Tokyo Night Day / Tokyo Night 语义色板；背景跟随网站，支持系统与手动主题。
- 所有文章（包括草稿）必须包含城市和有效经纬度；不猜测坐标，不补虚构测试记录。

## 数据与组件

`src/lib/review-map.ts` 定义严格 `reviewGeoSchema`，集合要求 `geo.city`、`geo.latitude`（−90 至 90）、`geo.longitude`（−180 至 180）。两类文章模板保留 null 坐标，作者填入实测城市位置后才通过校验。当前仅 100TB 洛杉矶文章，城市坐标沿用项目现有地理数据，正文不变。

`src/pages/map.astro` 从发布集合聚合城市并服务端输出文章链接；`MapArticle.astro` 显示文章卡片。`src/scripts/review-map.ts` 管理城市弹层、VPS / 独服列表筛选与查询参数；`review-globe.ts` 按需加载 Three.js，提供拖动、缩放、键盘控制及平滑定位。草稿和外部历史引用不进入地图。

地理轮廓使用本地 `public/globe/geography-50m.json`，来源、许可与转换说明见 `docs/assets/review-globe.md`。跨日期变更线与极区采用连续轮廓处理。无 Google API、外部瓦片请求或付费地图依赖。

## 缓慢自转与悬停暂停

移除右上角城市选择按钮；地球加载失败时仍保留「浏览测评」降级入口。按时间增量旋转，目标速度 2°/秒，约三分钟一圈；恢复时以 0.6 秒时间常数逐步加速，暂停立即生效。鼠标移入地球区域、触屏按住、键盘操作或弹层打开时暂停；退出交互后恢复。后台页面、离屏地球停止动画调度，恢复时重置时间避免跳转；遵循系统减少动态效果设置。

浏览器实测自转、悬停暂停、移出恢复、弹层暂停／关闭恢复、减少动效静止、手机触摸按住／松开，以及入口移除，无页面异常或手机横向溢出。格式、类型、构建和 map／content／release／readable／SEO 检查通过，日志 `test-results/review-globe/autorotate-checks.log`。仅本地预览。

### 自转未恢复修复

用户随后反馈自转未生效。复现两个暂停问题：整个矩形地图容器都被当作悬停区域；键盘聚焦地球后切回鼠标，键盘暂停状态未解除。改为根据球面投影轮廓和操作按钮判断悬停，地球周围空白不暂停；鼠标移动解除键盘交互状态，窗口失焦清理遗留指针。保持原转速，不取消减少动效保护。

新增 `scripts/verify-globe-motion-browser.js`，修复前实际捕获空白区域及键鼠切换两项失败，修复后独立无界面 Chrome 的 8 项回归全部通过：自转、球体悬停、空白区域恢复、键盘暂停、切回鼠标恢复、弹层暂停／恢复、减少动效。测试不操作用户正在使用的预览窗口。检查日志 `test-results/review-globe/autorotate-fix-checks.log`。未提交或部署。

## 城市测评弹层

按用户要求移除右侧常驻列表。城市标记打开仅属于该城市的测评列表，桌面居中弹窗，手机底部弹层；按后续要求移除右上角「选择城市」入口。列表仍为集合数据服务端渲染，VPS / 独服筛选只影响弹层，不改变地球覆盖统计。无对应类型时保留城市标题并显示空状态。

使用原生 dialog，关闭按钮、Escape、点击遮罩均可关闭；背景滚动锁定，Tab / Shift+Tab 在弹层内循环，关闭后恢复城市或入口焦点且不跳动页面。城市查询参数可直接打开弹层。无 WebGL 时从错误状态按钮进入列表；无 JavaScript 时显示静态备用列表。
